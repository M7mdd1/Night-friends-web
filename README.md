# شوطابيم — لعبة جماعية عربية

لعبة عربية متعددة اللاعبين، تعمل بخادم Node.js واتصال Socket.IO لحظي، وتخزّن الغرف والجولات في PostgreSQL المشترك. الواجهة الأصلية البنفسجية تدعم العربية RTL والوضعين الداكن والفاتح.

## التشغيل على Replit

1. فعّل قاعدة PostgreSQL المدمجة للمشروع؛ يستخدم التطبيق متغير `DATABASE_URL` الذي يوفّره Replit.
2. شغّل `npm run db:setup` مرة واحدة على قاعدة التطوير لإنشاء جدول الغرف.
3. شغّل التطبيق باستخدام `npm start` (أو Workflow «Start application»).
4. أنشئ غرفة، ثم انسخ رابط الانضمام وأرسله للاعبين. يمكنهم أيضًا فتح الموقع وإدخال رمز الغرفة واسم اللاعب.
5. عند النشر، انشر قاعدة التطوير مع التطبيق عبر Publish حتى يطبّق Replit تغييرات المخطط على قاعدة الإنتاج.

لا يحتاج التطبيق إلى مفتاح API خارجي أو خدمة طرف ثالث. لا تفتح `index.html` مباشرة؛ افتح الموقع عبر الخادم حتى يعمل الاتصال الفوري.

## صلاحيات اللعب

- المضيف ينشئ الغرفة ويدير المؤقت والفئات والجولات والفرق والنقاط.
- اللاعبون يشاهدون الحالة نفسها مباشرة ولا يمكنهم تغيير الحالة المشتركة.
- يمكن استعادة دور المضيف أو اللاعب بعد تحديث الصفحة على الجهاز نفسه.
- رموز الجلسات سرية ويُخزّن تجزئتها فقط في قاعدة البيانات.

## التطوير

- مصدر المخطط: `db/schema.sql`.
- إعداد التطوير: `npm run db:setup`.
- فحص صحة الخدمة: `/health`.
- الغرف تحفظ في PostgreSQL؛ رسائل PostgreSQL `LISTEN/NOTIFY` تنقل تحديثاتها بين نسخ الخادم.
